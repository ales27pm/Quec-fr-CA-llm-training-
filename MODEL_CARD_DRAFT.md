# Model Card Draft — Québec French adaptation workflow

This repository does not publish a finalized model by default. This draft describes the intended model adaptation workflow.

## Base models referenced

- `dphn/Dolphin3.0-Qwen2.5-3b`: preferred continuation base when preserving Dolphin instruction/personality behaviour.
- `Qwen/Qwen2.5-3B`: upstream clean base for ablation or clean-base experiments.
- `bartowski/Dolphin3.0-Qwen2.5-3b-GGUF`: runtime reference only; not a training source.

## Intended use

- Québec French adaptation research.
- Local LoRA/QLoRA experiments.
- Evaluation of lexical, syntactic, and regional Québec French behaviours.
- Controlled pipeline validation before any public model release.

## Not intended for

- Training from GGUF files.
- Training on holdout/evaluation-only resources.
- Commercial release without source/license review.
- Claims of complete Québec French coverage.
- Replacement for human review of sensitive data.

## Training data policy

Only records that pass source validation, curation, duplicate checks, permission checks, holdout filtering, and training-pack audit should be used. Pending, rejected, permission-required, unclear-license, or holdout records must be blocked unless policy explicitly permits them.

## Synthetic data policy

Instruction examples generated by the pipeline may be synthetic or derived. Model cards for released adapters must disclose the share of raw-preserved, extractive, templated, and synthetic examples.

## Evaluation policy

Evaluation holdouts such as QFrBLiMP, QFrCoRE/QFrCoRT, COLE, and similar benchmark resources must remain evaluation-only unless their maintainers explicitly state otherwise.

## Release checklist

Before releasing a model or adapter:

1. Confirm base model license.
2. Confirm training data licenses and permissions.
3. Confirm no holdout contamination.
4. Publish dataset card and model card.
5. Publish source attribution and third-party notices.
6. Report synthetic/derived-example share.
7. Report known Québec French weaknesses and failure modes.
