# Data governance

This repository prepares candidate Québec French data for validation, curation, evaluation, and possible model training. It is designed to block unsafe or unclear material by default.

## Core principles

1. Preserve Québec French markers; do not normalize to generic fr-FR.
2. Keep evaluation holdouts out of training data.
3. Preserve source, license, consent, review, and provenance fields.
4. Reject or quarantine unclear, duplicate, permission-required, holdout, or unsafe records.
5. Treat commercial release as stricter than local research.
6. Clearly label synthetic and derived examples.

## Source classes

- `training_approved`: source may be used for training under current policy.
- `evaluation_only`: source may be used for evaluation but not training.
- `holdout_only`: benchmark/holdout material; never train on it.
- `catalog_only`: reference entry only; no ingestion.
- `permission_required`: blocked unless an explicit grant is present.
- `excluded`: intentionally blocked.

## Pack modes

- `fixture_ci`: deterministic small-scale validation only.
- `local_research`: local experimentation; not commercial release material.
- `production_commercial`: strict mode for commercial release candidates.

## Synthetic and derived examples

Training-pack examples generated by templates, extraction, normalization, contrast prompts, summaries, or QA construction must carry synthetic/derived metadata. Raw preserved text should remain distinguishable from pipeline-generated instruction examples.

Recommended fields:

```json
{
  "synthetic_component": true,
  "generated_by_pipeline": true,
  "generation_method": "deterministic_template_or_extractive",
  "human_verified": false
}
```

For raw-preservation examples:

```json
{
  "synthetic_component": false,
  "generated_by_pipeline": false,
  "generation_method": "preserve_raw",
  "human_verified": false
}
```

## Release requirement

Before public release, commercial training, or publication, run validation, curation, contamination checks, training-pack audit, source/license review, and dataset/model-card review.
